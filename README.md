# Mohamed Salah | Engineering Portfolio

My personal portfolio, introducing my work in IoT, embedded systems, and AI-assisted systems.

**[Visit the portfolio](https://mosalah34.github.io/ENG_Mhamed-Salah/)**

## Featured work

- **Smart Event Hall:** QR access, environmental monitoring, and a web dashboard.
- **Smart Greenhouse:** camera-based plant monitoring and automated irrigation and cooling.
- **Smart Trash Bin:** fill-level sensing, lid automation, and LCD feedback.
- **Player Performance AI:** Python-based performance analysis and prediction.

The website presents these projects. For implementation details, firmware, or datasets for a featured project, contact me.

## Website stack

HTML, CSS, and JavaScript, with GSAP animations and a Three.js background.

## View locally

Download or clone the repository, then serve its files with a local web server. For example, with Python installed:

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in a browser.
